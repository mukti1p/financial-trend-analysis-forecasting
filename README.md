# financial-trend-analysis-forecasting
Trend analysis and financial forecasting project demonstrating moving average and regression techniques for a junior financial analyst.
# Week 4 – Trend Analysis and Forecasting in Financial Reporting

## Project Overview

This project demonstrates a forward-looking financial analysis for ABC Manufacturing Ltd., a hypothetical manufacturing company. It uses 24 months of historical financial data from January 2025 to December 2026 to identify trends and develop short-term forecasts for January to June 2027.

The analysis applies:

- Historical trend analysis
- Month-on-month growth analysis
- Three-month simple moving average
- Simple linear regression
- Forecast comparison
- Financial KPI and margin analysis
- Management recommendations

## Key Findings

- Revenue shows a sustained upward trend.
- Estimated annualised revenue growth is approximately 7.0%.
- EBITDA margin improves over the historical period.
- The regression model provides a measurable long-term trend benchmark.
- The moving-average model provides a short-term smoothing benchmark.
